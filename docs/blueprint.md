# **App Name**: 로또팡팡

## Core Features:

- 로또 번호 생성: 사용자가 버튼을 클릭하면 1부터 45 사이의 겹치지 않는 무작위 숫자 6개를 생성합니다.
- 생성 번호 표시: 생성된 6개의 로또 번호를 크고 명확하게 사용자 인터페이스에 표시합니다.
- 행운 메시지 제안 (AI tool): 생성된 번호 조합이나 로또 추첨의 행운에 대한 긍정적이고 독특한 AI 생성 메시지 또는 짧은 문구를 제공하는 도구입니다.

## Style Guidelines:

- Primary color: Optimistic and deep blue (#667FFF) to evoke a sense of hope and clarity.
- Background color: A subtle, light periwinkle-grey (#ECF0F6), derived from the primary hue, providing a clean and calming canvas.
- Accent color: A vibrant, clear sky-blue (#1AB3FF) used for interactive elements like buttons and highlights, creating good contrast and energetic pop.
- Body and headline font: 'Poppins' (sans-serif) for a modern, geometric, and precise look, enhancing readability for numbers and short texts.
- Use clean, vector-based icons related to luck, lotteries, or numbers, such as a four-leaf clover, a star, or a stylized number 'ball'.
- A clean, center-aligned layout that highlights the generated numbers with generous whitespace for visual breathing room. Ensure responsiveness across devices.
- Subtle animations for number generation, such as numbers smoothly fading in or 'rolling' into place, and engaging hover effects on buttons.
